# Master V1 Quality Gate

## Automatic Requirements

The final episode plan must pass `validate_episode_plan.py --stage final`.

## Visual Review

Score every item pass/fail:

1. All six shot jobs are immediately understandable.
2. Every product interface shown is real and readable.
3. Every spoken claim has visible or recorded evidence.
4. S03 shows one coherent operation rather than a montage.
5. S04 shows the actual result of S03.
6. Typography uses the fixed hierarchy and bottom safe area remains clear.
7. Only one source-native accent color is used.
8. Motion uses only the fixed Master V1 set.
9. No text collision, clipping, empty fake UI, or low-resolution enlargement is visible.
10. The final URL holds fully readable for at least 24 frames.

All ten must pass.

## Audio Review

1. Dayi is used for all six segments.
2. No segment crosses its shot boundary.
3. Delivery is consistent across segments.
4. No word is clipped at a cut.
5. The final sentence resolves before the last URL hold.

All five must pass.

## Series Consistency Review

Compare S01, S03, S04, and S06 against the last approved Master V1 episode:

- Same type hierarchy.
- Same caption placement.
- Same motion vocabulary.
- Same density.
- Same closing behavior.

If the difference cannot be explained by the real website content, treat it as random variation and revise.

## Handoff Language

Use:

- `视觉草稿`: visuals exist but voice or final QA is incomplete.
- `待审样片`: full timeline exists and internal QA passed, awaiting user approval.
- `Master V1 成片`: user approved the rendered result and any requested export completed.

Never call a first-pass experiment a finished episode.
