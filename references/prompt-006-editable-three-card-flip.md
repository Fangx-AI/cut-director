# Prompt 006: 浅灰三卡翻面（正反面可编辑）

这个 Prompt 把已验证的原版三卡翻面镜头变成用户可以直接换内容的通用模板。固定的是三卡构图与翻面语言；可替换的是六个卡面的文字、图片和强调色。演示里的标题与指标只是示例，不是模板的固定内容。

> **类型：可编辑 Motion Graphic。** 三张卡的正面和背面共六个卡面都能分别替换，复用的是构图、样式和翻面节奏，不是演示中的固定文案。

[观看已验证演示视频](../assets/verified-prompts/prompt-006-editable-three-card-flip.mp4)

## 用户直接使用的通用 Prompt

```text
在 [目标时间段] 制作一段原版浅灰三卡依次翻面镜头。保留三张横向并排的白色卡片、浅灰背景、左上角小标题，以及原版的卡片尺寸、间距、层级、透视和从左到右错峰节奏；固定三张卡片，不自动增减，也不要重新设计成深色、玻璃拟态或其他视觉风格。

三张卡片的正面和背面必须分别独立可编辑。请使用以下内容：
- 卡片 1 正面：[正面内容]；卡片 1 背面：[背面内容]
- 卡片 2 正面：[正面内容]；卡片 2 背面：[背面内容]
- 卡片 3 正面：[正面内容]；卡片 3 背面：[背面内容]

每个卡面可填写标题、副标题、分类、说明、指标和用户提供或项目中已验证的图片。未填写的可选字段直接隐藏并自动回流，禁止留下骨架线、灰色占位块、空白图片区或伪造内容；每个卡面至少保留一项真实、可读的内容。所有文案都保留为 Motion Graphic 可编辑文字图层，不得烘焙进 PNG、截图或视频。图片只使用用户提供或项目中已验证的真实素材，不生成、重绘或虚构产品 UI。

翻转使用 Y 轴原地翻面：先稳定展示三张正面，再让卡片 1、2、3 依次翻转。只有卡片接近 90°、画面最窄的边缘态时才能切换正反面；背面落稳后必须正向可读，禁止镜像字、反字或在翻转中途闪回另一面。独立演示默认使用 1920×1080、30fps、3 秒：正面保持到第 20 帧，三张卡分别从第 20、32、44 帧开始翻转，每张用 16 帧完成，全部背面在第 60 帧落稳并保持到结尾。目标时长不足时优先延长片段、精简卡面文案或依次完成翻转，不得靠过度加速牺牲可读性。

不添加辉光、粒子、玻璃拟态、随机旋转、夸张弹跳、大标题或无关装饰。先展示正面稳定态、至少一个 90° 边缘态、每张背面落稳后的状态和最终保持帧，并提供实时播放预览让我确认；导出前再次检查六个卡面的文字与图片都能独立修改。
```

## 用户需要替换什么

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 左上角小标题 | 否 | 留空时隐藏，不保留空容器 |
| 卡片 1–3 正面 | 是 | 每个正面至少保留一项真实文字或已验证图片 |
| 卡片 1–3 背面 | 是 | 每个背面至少保留一项真实文字、指标或已验证图片 |
| 分类、说明、辅助标签 | 否 | 留空后自动回流，不显示骨架线 |
| 卡面图片 | 否 | 只使用用户提供或项目中已验证的真实素材 |
| 强调色 | 否 | 默认沿用三张卡各自的克制强调色 |

“可编辑”不是只换三个背面数字。六个卡面都必须分别暴露为 Motion Graphic 属性；用户可以独立替换正面标题、正面说明、背面标题、背面指标、背面说明和可选图片。

## 固定的原版样式

- 画幅：1920×1080，30fps。
- 默认时长：90 帧（3 秒）。
- 背景：`#EDEDEB` 浅灰。
- 卡片：三张 414×230 白色卡片，水平居中并排。
- 标题：左上角小号黑色标题，不使用大号居中主标题。
- 运动：Y 轴原地翻面，从左到右错峰。
- 视觉：克制、平面、轻阴影；不改成暗色科技风、玻璃拟态或发光卡片。

如果用户要求不同颜色或文字，可以修改内容属性；如果用户要求改变卡片数量、瀑布流或完全不同的动画结构，应改用其他 Prompt，而不是让 006 自动变形。

## 默认时间轴

| 帧 | 状态 |
| --- | --- |
| 0–19 | 三张正面稳定展示 |
| 20–35 | 卡片 1 翻转，约 90° 时切换到背面 |
| 32–47 | 卡片 2 翻转，约 90° 时切换到背面 |
| 44–59 | 卡片 3 翻转，约 90° 时切换到背面 |
| 60–89 | 三张背面全部落稳并保持 |

目标片段比 3 秒短时，不要把翻面压成不可读的一闪而过。优先延长片段、隐藏可选字段或请求新的时间段。

## 默认执行方式

1. 读取目标时间段、画幅、帧率和需要保护的字幕、人物、Logo 或产品 UI。
2. 收集三张卡的六个卡面内容，确认每个卡面至少有一项真实可读内容。
3. 用 Motion Graphic 属性建立六个独立卡面；文字不烘焙，未填写字段隐藏并回流。
4. 按原版 1→2→3 的节奏完成 Y 轴翻面，只在约 90° 边缘态切换卡面。
5. 检查正面稳定态、三次边缘态、三个背面落稳态和最终保持帧。
6. 以 H.264、1920×1080、30fps 导出并复核实际成片。

## 验证清单

- 三张卡的正面和背面均可独立修改，不是把示例内容固定进模板。
- 六个卡面没有骨架线、灰色占位块、空白图片区或伪造内容。
- 所有文案仍是可编辑 Motion Graphic 文字，不在 PNG、截图或视频中。
- 三张卡只在约 90° 的最窄边缘态切换正反面。
- 背面落稳后文字正向可读，没有镜像、反字或闪回。
- 最终背面保持到结尾，没有黑帧、突缩、回正面或突兀退场。
- 导出为 H.264、1920×1080、30fps。
