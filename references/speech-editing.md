# 中文口播语音剪辑

目标是听起来完整、利落、自然。ASR 是定位线索，音频决定实际说了什么；静音检测只能给出候选。

## 根据任务选择力度

| 请求 | 默认处理 |
| --- | --- |
| 去口癖、重录、剪干净 | 清理无意义犹豫、口误后的失败尝试、制作闲聊、冗余副本和空等；保持观点顺序 |
| 节奏紧一点 | 在清理基础上压缩空等和拖沓衔接，保护完整发音与必要气口 |
| 精简到指定时长 | 优先去冗余，再按信息价值取舍；无法无损达到时长时展示具体取舍 |
| 重新组织、结论提前 | 可在授权范围内调整完整语义单元，检查指代、铺垫、因果和连接词 |
| 只加动画、只改字幕 | 复用当前语音剪辑，不清理 A-roll |

不要把“清理”扩大成删除不喜欢的观点。独有例子、解释、适用条件或反例不是天然废话。

## 语气词与口癖

逐一判断：是否纯犹豫、是否提供语义或态度、删后是否自然。

| 原声 | 处理 | 原因 |
| --- | --- | --- |
| “呃……今天说三个方法。” | 可删孤立的犹豫音 | 不承载信息，确认发音边界后剪 |
| “这个，嗯，这个工具可以导出。” | 可清理犹豫和失败重复 | 保留一版完整主语 |
| “然后我们再看第二步。” | 保留“然后” | 标记步骤顺序 |
| “不是免费，而是限时免费。” | 保留对比与限定 | 删除会改变事实 |
| “那个方案更适合初学者。” | 保留“那个” | 指向前面提到的对象 |
| “真的，真的很重要。” | 结合声调判断，通常保留 | 可能承担强调 |
| “免费额度够用。” | 保留整个词“额度” | 字符“额”不是犹豫词 |
| “其实这个功能还没上线。” | 保留必要的态度与否定 | 不能按词表删“其实”或“还没” |

纯固定犹豫音可以使用当前宿主的批处理能力，但先核对它按词还是按字符匹配、支持哪些语言。中文拆字或不确定的转写使用 Script 局部删除，不全局替换。若犹豫本身构成笑点、情绪、真实反应，则保留。

## 重复录制、口误与未完成句

1. 判断是否同一个意图被重新尝试。相似句可能是强调、回扣、总结，或补上新条件。
2. 找到完整、正确且表达最好的一版。较后录制可以优先比较，但不机械保留最后一版。
3. 删除被覆盖的失败内容，保留独有的引入、主体、步骤编号或限定条件。
4. 检查新相邻句是否能自然连接，不跨尝试拼接半句话制造没说过的结论。

例如：

```text
原声：先说价格，这个工具每月九十……我说错了，每月十九元。
保留：先说价格，这个工具每月十九元。
前提：后一句是完整修正，接缝经过词点和音频检查；“先说价格”仍有结构作用。

原声：这是免费版。免费版每天只能导出三次。
保留：这是免费版。免费版每天只能导出三次。
原因：第二句新增次数限制，不是失败重录。

原声：第二点是隐私，第二点……所有文件都留在本地。
保留：第二点是隐私，所有文件都留在本地。
原因：保留完整引入，只删除失败重启。
```

数字、否定、单位或身份听不清时，试听对应窗口，不能凭视觉猜一个更合理的值。参考稿与录制冲突时标出差异，录制内容是剪辑事实来源。

## 冗余句与制作闲聊

可清理完全被保留句覆盖的第二遍解释，或“刚才说错了，重来”“这句后期删掉”等确定在对剪辑者说的话。引用这种话作为例子时保留。

整句删除前检查其是否提供：新事实、因果、例子、限制、转折、说话者态度、下一句的指代对象。如果有，按精简任务的要求选择，普通去口癖请求中先保留。

不要自动删除开头结尾、CTA、停顿中的表情或所有重复出现的品牌名。不要为满足目标时长制造新的承诺。

## 停顿、呼吸与节奏

默认自然节奏；以下是未指定参数时的试听起点，不是所有间隔的硬门槛：

| 节奏 | 优先检查的空等 | 剪后气口参考 |
| --- | --- | --- |
| 舒缓 | 明显拖沓、约 0.9 秒以上 | 约 0.35–0.55 秒 |
| 自然 | 明显空等、约 0.6 秒以上 | 约 0.2–0.35 秒 |
| 紧凑 | 约 0.4 秒以上且不承担表达 | 约 0.12–0.25 秒 |

保留提问、转折、揭示、笑点和章节变化的停顿。短吸气和轻声字不是空等。长停顿夹在同一句里时压缩，接缝两侧保留量合计才是最终气口。用户指定阈值时直接遵循。

不要在主视频轨创建空 gap 充当呼吸；保留原素材中的气口。变速是独立处理，不能靠加速整个视频替代语义剪辑。

## 保留与恢复

第一次写入前保存当前 Script、源媒体身份、源时间范围和已有字幕/效果锚点。保留原媒体，不覆盖原文件；宿主支持项目副本或版本快照时优先使用。缓存放在项目的私有工作目录，不把用户原文、声音或文件路径提交到公开仓库。

每次删减保留实际原句、源区间、原因和粗剪版本。用户说“这句别删”时，按原句与上下文找到被删源片段，在当前版本恢复相应位置；不能只向字幕补字，也不能依赖多次全局撤销破坏已接受的其他修改。

恢复后回读实际 Script，确认没有重复导入、旧失败版本或意外空白，再试听相邻接缝，更新受影响字幕与效果的时间。如果素材已替换、旧身份无法解析或恢复机制不可靠，先报告具体缺口，不猜另一个文件或伪造恢复成功。

## 剪点与当前宿主

- 先加载当前 talking-head / transcription 指南和工具 schema。`read_script` / `apply_script` 用于实际语音选择；`manage_transcript` 修正 ASR；`find_transcript` 定位词点。
- `clean_script` 会立即写入时，预览请求不能先调用它。把拟删内容和停顿调整一起放入 Script，使用当前支持的 preview。
- 普通清理可先执行确定性的机械处理再回读，或用一次 Script 批次同时处理；语义编辑必须基于最新生成的 Script。不能拿前一次清理前的行号继续写。
- ASR 行不是句子，完整观点可能跨行，一行也可能包含多个语义单元。删整行前重建上下文。
- 精剪单词需实际词点和试听。保留爆破音、辅音起始与词尾；需要时留少量源音频余量。不能为了不碰 ASR 区间，把已删口癖的声音带回来。
- 分割、删除和压缩保持原声与视频同步。已有字幕、音效、B-roll 或多机位要用宿主的 linked / ripple 行为处理，再回读；不猜它们一定自动移动。
- 用户要求只预览时停在预览；应用已获授权时，preview 成功后直接应用。工具失败后先读实际状态，避免重放已成功的半批操作。

## 写后检查与局部修复

回读保留原文并试听修改处：是否断字、爆音、主谓缺失、指代悬空、停顿太紧、重复遗漏。查人物口型和跳切，必要时选择更好剪点、保留气口或使用有关的辅助画面。

继续做字幕与动画前读取剪后时间线。若之后恢复一句或再删一段，更新版本与映射，重新生成受影响字幕和重锚动画；旧版证据不能证明新版正确。

不要声称只凭转写就完成了自然度、声画同步或交付文件验证。
