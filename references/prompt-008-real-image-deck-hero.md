# Prompt 008: 真实图片卡组飞入与主卡落位

这个 Prompt 把 3–5 张用户提供的真实图片组织成卡组飞入、展开和主卡抬升的完整镜头。图片、卡片标题、标签、主卡序号与视觉样式都可替换。

> **类型：真实图片驱动的可编辑 Motion Graphic。** 声明几张卡就必须提供几张真实图片，不复制同一张图填数，也不生成或重绘产品 UI。

[观看已验证演示视频](../assets/verified-prompts/prompt-008-real-image-deck-hero.mp4)

## 用户直接使用的通用 Prompt

```text
在 [目标时间段] 制作一段“真实图片卡组飞入与主卡落位”镜头。独立演示默认使用 1920×1080、30fps、3 秒。使用用户提供或当前项目中来源可验证的 3–5 张真实图片：[图片 1]、[图片 2]、[图片 3]、[可选图片 4]、[可选图片 5]；同时填写每张卡片各自的 [标签] 与 [标题]，并指定 [主卡序号]。cardCount 必须与真实图片数量一致，heroIndex 必须指向其中一张有效卡片；禁止重复图片凑数、生成或重绘产品 UI、显示空白图片区、骨架线或占位词。

把每张图片、标签和标题保留为独立可编辑属性，并额外开放场景标签、深色背景、浅色背景、卡片底色、主文字色、辅助文字色、强调色和字体。图片统一使用 contain 完整显示，不裁掉界面边缘或关键信息；可选标签留空时隐藏并自动回流。3 张卡使用约 430×318 的卡面，4 张约 355×276，5 张约 292×242，始终保持清晰可读。

动画节奏固定为：每张卡从第 index×3 帧开始，用 12 帧依次从画面外飞入；第 16–48 帧让卡组从倾斜叠放状态收束成稳定扇形；背景第 0–42 帧由深色过渡到浅色；指定主卡第 30–52 帧抬升并放大到约 1.12 倍，其他卡退为陪衬；第 52 帧后稳定保持到第 89 帧。场景标签只在开头第 0–10 帧克制出现，不添加随机旋转、粒子、辉光、无关大标题或连续弹跳。

先展示首张卡飞入、全部卡片出现、卡组收束、主卡抬升和最终保持帧；逐张核对图片来源、完整显示、标题对应关系、主卡序号和最终可读性后再导出。
```

## 用户需要替换什么

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| cardCount | 是 | 只能是 3–5，必须等于真实图片数量 |
| card1Image…card5Image | 按 cardCount | 每张都来自用户或项目已验证素材 |
| card1Label / card1Title… | 标题必填，标签可选 | 各卡独立可编辑；空标签隐藏 |
| heroIndex | 是 | 指向有效卡片，决定最终主卡 |
| sceneLabel / 色彩 / 字体 | 否 | 只改包装，不改变真实图片内容 |

## 固定的动画骨架

- 画布：1920×1080，30fps，90 帧。
- 进场：每卡错开 3 帧，单卡用 12 帧飞入。
- 收束：第 16–48 帧形成稳定扇形。
- 背景：第 0–42 帧由深到浅。
- 主卡：第 30–52 帧抬升到约 1.12 倍。
- 收尾：第 52–89 帧保持，不突然散开或闪黑。

## 真实素材边界

卡片只是承载真实图片的后期容器。没有足够图片时减少 cardCount 或请求素材，不能复制图片、生成界面、放灰色占位块或用虚构文案补齐。

## 验证清单

- cardCount 与真实图片数量一致，heroIndex 有效。
- 每张图都完整清晰，使用 contain，无裁切、拉伸或重复。
- 图片、标签、标题、主卡序号和颜色均可独立修改。
- 第 0、12、30、48、52、89 帧以及实时播放均无跳变或突兀收尾。
