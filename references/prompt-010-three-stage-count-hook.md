适合已有口播中的发布消息、合集开头、方法介绍。用“消息 → 数量与内容 → 观众能得到什么”建立观看预期。仅需解释一次操作的因果关系时，使用 Prompt 009。

## 直接使用的 Prompt

```text
在 [目标时间段] 制作三段式数字片头，沿用原片画幅和视觉风格。

第一段让「[发布消息]」以大字快速推入；第二段切到醒目的数字 [数量]，短暂跳数后稳定为准确数量，旁边显示「[内容单位]」；第三段让「[观众收益或提问]」错位滑入并落稳。每段只保留一个主视觉焦点，标题按口播关键词出现，不另外增加等待标题卡的时间。

把发布消息、数量、内容单位、收益句、字体、背景色、文字色、强调色与三段时长保留为可编辑属性。数量只来自提供的实际内容，不自动套用 30。无数量时改用核心关键词，不编造数字。

如已有相关、可验证的成果录屏，可在第二或第三段作为背景或短切画面；没有素材就用干净的文字构图，不补假界面。字号按最长文本与安全区调整，不照搬演示坐标。音乐与音效遵循原片设置，已有配乐时可让阶段切换贴近重拍，优先保证口播完整和文字可读。

演示可从约 6 秒起步，按实际口播调整三段占比。结尾保留短暂稳定状态，并检查与下一镜的衔接。展示每段落稳帧、两次切换和最终衔接，核对数量与文案，再导出。
```

## 替换项与演示范围

| 项目 | 本地示例 | 使用时 |
|---|---|---|
| 消息 | 新工具发布 | 换成已确认的口播原句 |
| 数量 / 单位 | 12 / 种实用方法 | 与实际内容一致 |
| 收益句 | 哪一个，你能用上？ | 换成当前视频的观看理由 |
| 视觉 | 深色、浅绿、细环 | 继承目标视频，不固定科技风 |
| 时长 | 6 秒，三段各约 2 秒 | 根据语义和可读性调整 |

本地演示只验证文字与数字动效，不包含成果录屏、配乐、人物替换或真实片头衔接。源文件通过 React props 修改内容；这不等于已验证 ChatCut MG 属性可编辑。长文案、竖屏重排和插入现有片段需另行检查。

源文件中的小标题与阶段条属于演示辅助元素，可删除。不是全片章节导航；需要全片进度时使用 Prompt 004。
