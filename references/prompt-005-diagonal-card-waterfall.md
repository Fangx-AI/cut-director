# Prompt 005: 斜向卡片瀑布墙

把真实网页、产品界面或作品截图组织成一面持续流动的空间卡片墙。这个效果的重点是“整面墙的统一空间运动”，不是在画面上叠标题、标签或装饰。

本 Prompt 已在 1920×1080、30fps 的 ChatCut 独立时间线中完成验证：检查了首帧、中段和最后可见帧，卡片没有黑边、断层或首尾缩放跳变。

## 用户直接使用的通用 Prompt

```text
在 [时间段，默认 8 秒] 制作一段 16:9 全屏“斜向卡片瀑布墙”动效。

使用 [6-12 张真实网页、产品界面或作品截图] 作为卡片内容。优先使用用户提供、项目中已有或从目标官方网站取得的真实画面；不得生成、重绘或虚构产品 UI。逐张检查来源、清晰度、纵横比和关键文字区域，文字密集的截图优先完整显示，不为填满卡片而裁掉核心信息。

将卡片排成至少 3 列，每列包含一组可重复的卡片。先把全部列组织成一块超出画布边界的统一平面，再对整块平面应用三维透视、轻微纵深倾斜和约 -6° 至 -10° 的画面旋转。卡片本身保持统一圆角、间距和阴影，不要让每张卡片各自旋转、漂浮或弹跳。

所有列沿这个倾斜平面的局部纵轴匀速向上滚动，屏幕中因此呈现稳定的斜向运动。不同列只使用起始相位偏移来打散排列，默认保持同一速度，避免互相追赶。复制完整卡片组覆盖循环前后，让首尾在同一位置和比例下无缝衔接；首帧不得额外缩放、淡入或弹性启动，结尾不得减速。

画面只保留卡片墙、必要的深色背景和克制暗角。不要添加大标题、字幕、系列角标、品牌角标、说明文字、粒子、故障、扫描线、持续辉光或无关装饰。需要标题或字幕时，由时间线中的其他独立图层负责，不要写进这个可复用特效。

开放以下可编辑属性：每张卡片图片、背景色、空卡片颜色、强调色、平面旋转角、纵深倾角、列间距、完整循环次数、暗角开关和透明背景开关。默认 8 秒完成 1 次整数循环；改变时长后仍按完整循环计算，不使用会造成首尾跳变的入场动画。

先展示首帧、中段和最后可见帧，并把首尾帧并排比较；确认没有黑边、空洞、卡片断层、纵横比变形、关键内容被裁切或循环跳变后，再让我播放实时预览。
```

## 视觉机制

| 层级 | 职责 |
| --- | --- |
| 卡片内容 | 真实截图或已验证的项目图片，只负责呈现素材本身 |
| 列 | 组织卡片和相位，不承担独立旋转或弹跳 |
| 卡片墙平面 | 统一执行透视、纵深倾斜和画面旋转 |
| 时间映射 | 线性、匀速、整数循环，保证首尾可接 |
| 边缘处理 | 用超出画布的内容和克制暗角隐藏裁切边界 |

关键原则：先构造一面足够大的连续墙，再移动这面墙。不要把效果误做成“很多卡片各自飞行”。

## 素材策略

1. 用户提供的真实截图。
2. 当前 ChatCut 项目中已有的网页、产品或作品图片。
3. 目标官方网站、官方文档或官方演示中的可验证截图。
4. 只有在真实素材暂时不足、且用户明确接受示意占位时，才使用无文字的中性 UI 骨架卡。

不得使用生成图片伪装成真实软件界面，也不得用截图中的品牌信息推断或补写不存在的功能。

## 默认参数

| 参数 | 建议值 |
| --- | --- |
| 画幅 | 1920×1080，16:9 |
| 时长 | 8 秒 |
| 列数 | 3 列 |
| 平面旋转 | -7.5° |
| 纵深倾角 | 8° |
| 完整循环 | 1 次 |
| 运动曲线 | 线性 |
| 背景 | 近黑 |
| 额外文字 | 无 |

这些是已验证起点，不是跨项目的硬编码。竖屏或方形项目应重新计算列宽、超出画布的范围和旋转中心。

## 验证清单

- 首帧已经处于稳定滚动状态，没有额外缩放或淡入。
- 中段卡片覆盖完整，没有黑边、空洞或列间断层。
- 最后可见帧与首帧的构图只相差正常的一帧线性位移。
- 真实截图没有被拉伸，核心文字或控件没有被无意义裁切。
- 整面墙统一倾斜；单张卡片没有独立乱转、漂浮或弹跳。
- 没有标题、字幕、角标或装饰层抢占素材注意力。
