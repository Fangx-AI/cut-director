# Prompt 005: Page Waterfall Wall 斜向卡片滚动

这个 Prompt 对应网站或工具已经提供的 `page-waterfall-wall.mp4`。它的首要原则是复用真实源视频，而不是看到相似画面后重新生成一套卡片、文字和动画。

> **类型：真实源视频复用型。** 卡片文字、图片和运动已经烘焙在源视频中，不能通过这个 Prompt 替换。需要编辑卡片内容时，不要使用 Prompt 005，应选择可编辑 Motion Graphic Prompt。

[观看已验证演示视频](../assets/verified-prompts/prompt-005-diagonal-card-waterfall.mp4)

## 用户直接使用的通用 Prompt

```text
在 [目标时间段] 使用 page-waterfall-wall 斜向卡片滚动镜头。

先检查目标网站、官方演示和当前 ChatCut 素材库。若已经存在网站提供或官方来源的 `page-waterfall-wall.mp4`，直接导入并使用原视频，不重新生成、重绘或用 Motion Graphic 复刻。

保留原素材的 1920×1080、30fps、约 5 秒时长、播放速度和完整画面，不添加大标题、字幕、角标、品牌包装、粒子、故障或其他覆盖层。只有在目标画幅不一致时才做最小必要适配，禁止拉伸和无意义裁切。

只有确认不存在可用的真实源视频，并且得到用户明确同意后，才可以用真实网站截图或真实录屏复刻；不得生成、重绘或虚构产品 UI。无法取得可靠素材时保持画面干净并请求源文件。

先展示首帧、中段和尾帧，确认来源、画面完整、无覆盖、无裁切、无黑边后，以 H.264、1080p、30fps 导出。
```

## 素材优先级

| 优先级 | 素材 | 处理方式 |
| --- | --- | --- |
| 1 | 网站直接提供的 `page-waterfall-wall.mp4` | 原样导入、原速播放、完整使用 |
| 2 | 官方产品演示中的同一原始镜头 | 核验来源后截取完整镜头 |
| 3 | 当前 ChatCut 项目中已验证的同名素材 | 检查元数据和关键帧后直接使用 |
| 4 | 用户提供的原始视频 | 核验后直接使用 |
| 5 | 真实网站截图或真实录屏 | 仅在源视频不存在且用户明确同意复刻时使用 |

生成图片、虚构 UI、重绘品牌页面和“凭感觉做一个差不多的”不在素材链路内。

## 默认执行方式

1. 搜索网站下载内容、官方演示和当前项目素材库。
2. 检查文件名、来源、分辨率、帧率、时长和首、中、尾帧。
3. 把源视频作为唯一画面图层放进 1920×1080、30fps 时间线。
4. 保留原始播放速度和完整约 5 秒时长，不叠加标题、字幕或装饰。
5. 对首帧、中段、尾帧和导出文件做复核。
6. 以 H.264、1080p、30fps 导出。

## 什么时候才允许复刻

必须同时满足以下条件：

- 已经确认网站、官方演示、项目素材库和用户文件中没有可用源视频。
- 用户明确同意用真实截图或真实录屏复刻。
- 素材来源、内容真实性和使用范围可以核验。
- 先制作一个代表镜头并让用户确认。

任一条件不满足，就保持画面干净并请求源文件。
