# 字幕样式

默认用「朴素」。用户说"美化""花字""重点强调""像抖音那样"之类，或点名某一套时，才换成别的样式。换了样式，时间、文字、断句的规则照旧按 [subtitles.md](subtitles.md)，这里只管长什么样。

不管哪套样式：只改样式不改字，不加说话人没说过的话；不加表情、贴纸、音效；全片一套样式，不混用。

## 怎么选

| 样式 | 适合 | 一句话 |
| --- | --- | --- |
| 朴素（默认） | 什么都适合 | 白字黑边，一行一行 |
| 重点高亮 | 讲观点、讲干货 | 朴素的基础上，少数关键词变黄、略放大 |
| 逐字跟读 | 节奏快的短视频 | 正在说的字变色 |
| 综艺大字 | 情绪强、娱乐向 | 更大更粗，关键词换色并弹一下 |
| 半透明底 | 背景杂乱、字看不清 | 字下面垫一条半透明深色底 |

用户只说"美化一下"没点名时，用「重点高亮」。

## 共同参数

用 ASS 实现。`PlayResX`、`PlayResY` 设成成片的宽高，下面的尺寸都按画面宽度 W 算，位置按 [subtitles.md](subtitles.md#位置和样式) 先量下巴再定，`MarginV` 用画面底边到字幕底边的距离。

字体：优先用户的品牌字体；没有就用清晰的粗黑体，例如思源黑体 / Noto Sans SC 的 Bold 或 Heavy。用的字体文件放在烧字幕时能找到的地方（ffmpeg `subtitles=...:fontsdir=...`），出片后抽帧确认不是回退字体。

颜色写法：ASS 是 `&HAABBGGRR`，黄色 #FFD400 写成 `&H0000D4FF`。

## 朴素（默认）

就是 [subtitles.md](subtitles.md#位置和样式) 里的样式：字号约 0.055W，白字，描边约字号的 5%，淡阴影。

```text
Style: Plain,<字体>,<0.055W>,&H00FFFFFF,&H00FFFFFF,&H00000000,&H64000000,-1,0,0,0,100,100,0,0,1,<字号×0.05>,<字号×0.03>,2,<0.05W>,<0.05W>,<MarginV>,1
```

## 重点高亮

在朴素的基础上：

- 字号可到 0.06W，描边加到字号的 7%–8%，阴影略柔（`\blur1`）。
- 每屏最多高亮一个词或短语：亮黄 `&H0000D4FF`，放大到 115%。写法：`{\c&H0000D4FF&\fscx115\fscy115}关键词{\r}`。
- 全片三到四成的屏有高亮就够，一屏都想高亮等于没有高亮。
- 每屏 0.12 秒淡入：行首加 `{\fad(120,0)}`。不做逐字跳动。

挑哪个词，按顺序：

1. 这句话的结论或反差（"不准确""免费""最重要"）
2. 产品名、技术名、人名（GitHub、Claude、上下文）
3. 确切的数字（"3 个""99%"）

不高亮：代词、连词、助词、语气词，以及刚高亮过的同一个词（隔几屏再出现可以再亮一次）。

## 逐字跟读

一屏一行不变，正在说的字从白变成高亮色，说过的保持高亮色。用逐字转写的时间，按 [subtitles.md](subtitles.md#时间) 换算到成片后，每个字写一个 `\kf`（单位厘秒）：

```text
Style: Karaoke,<字体>,<0.06W>,&H0000D4FF,&H00FFFFFF,&H00000000,&H64000000,-1,0,0,0,100,100,0,0,1,<字号×0.07>,<字号×0.03>,2,<0.05W>,<0.05W>,<MarginV>,1
Dialogue: 0,0:00:01.20,0:00:02.60,Karaoke,,0,0,0,,{\kf32}今{\kf28}天{\kf40}聊{\kf30}聊 {\kf50}GitHub
```

- `PrimaryColour` 是变色后的颜色，`SecondaryColour` 是还没说到的颜色。
- 一个英文单词或一串数字算一个单位，不按字母拆。
- 字与字之间的停顿并到前一个字的时长里，不然颜色会提前跳。

## 综艺大字

- 字号 0.07–0.08W，字体用最粗的一档，描边字号的 10%，阴影更重。字太大一行放不下时，按 [subtitles.md](subtitles.md#断句) 拆成更短的屏，不要缩字号也不要换两行。
- 每屏出现时轻轻弹一下：`{\fscx110\fscy110\t(0,120,\fscx100\fscy100)}`。
- 关键词规则同「重点高亮」，颜色可以换成用户的品牌色。
- 这套最容易挡脸，抽帧时多看几处手势和凑近镜头的地方。

## 半透明底

- 字号同朴素，`BorderStyle` 设 3（不透明底框），`OutlineColour` 用来当底色，例如 `&H80000000`（约 50% 透明的黑）。`Outline` 控制底框比字大出多少，约字号的 25%。
- 可以和「重点高亮」叠用：底框照旧，关键词变黄。

```text
Style: Boxed,<字体>,<0.055W>,&H00FFFFFF,&H00FFFFFF,&H80000000,&H00000000,-1,0,0,0,100,100,0,0,3,<字号×0.25>,0,2,<0.05W>,<0.05W>,<MarginV>,1
```

## 自检

在 [subtitles.md](subtitles.md#自检) 的清单之外：

- 抽帧里至少有两屏带高亮或特效，确认颜色、放大、动画都生效，字体不是回退字体。
- 高亮的词没有拆开，高亮后整屏宽度仍不超过每行上限（放大的字按 1.15 倍算宽度）。
- 同时交一份 SRT：SRT 里是纯文字，没有样式标签。

## 参考

样式思路参考了 [pycaps](https://github.com/francozanardi/pycaps)（用规则或词表给词打标签再加样式）、[captametropolis](https://pypi.org/project/captametropolis/)（逐字高亮）和 [style-captions](https://github.com/gooseworks-ai/gooseworks-ads-skills)（命名的字幕预设）。这里只借鉴做法，没有复制代码或预设文件。
