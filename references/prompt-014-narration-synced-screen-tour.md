# Prompt 014: 旁白驱动的真实界面导览

让真实录屏中的鼠标、焦点、点击和页面反馈跟随讲解。适合软件教程、产品实操和复杂界面介绍，尤其用于修正“说到左边，鼠标却在右边”的错位。

> **状态：experimental。** 原片的实际导览镜头、逐词对应记录与最终视频帧已检查；换用新界面、新配音后的通用执行尚未重新渲染验证。原案卷素材不公开，本页没有公开视频，不应理解为已提供可编辑录屏模板。

## 用户直接使用的通用 Prompt

```text
把 [目标时间段] 的 [真实软件录屏] 做成跟随 [已批准配音] 的界面导览。先从实际配音提取方位词、对象名和动作词，整理“发声时间窗—目标区域—真实动作—页面反馈”的对应表，再安排画面；不要按稿子字数估算操作时间。

讲到某个区域时，让唯一一个与真实输入事件对应的鼠标指针已抵达目标旁边的空白位置；说到左侧、右侧或下方时，指针和焦点框必须同时位于对应区域。当前对象使用 [强调色] 细框或四角框，外围轻微压暗，保留原内容亮度与文字清晰度。指针不挡关键文字，只有真实点击发生时才产生短促点击光圈。

页面切换或弹窗打开前清除旧框，等真实内容出现后重新定位。长页面先滚动、停稳，再聚焦并讲解下一项；不要在该项讲完前把它滚走。保留点击、加载、反馈与结果的真实先后顺序，页面尚未就绪时不得提前显示或指向结果。

若现有画面与配音不匹配，优先剪除无意义等待、调整允许调整的停顿，或补录真实操作。局部变速只能用于不影响理解的移动与等待，保留源片到成片映射；不能改写业务数据、把失败剪成成功，或用虚构鼠标轨迹冒充操作。不同批次的结果示例要保留来源说明，不能宣称它是前一个点击立即产生的新结果。已批准配音与页面原有文字保持，本镜头不自动增加逐句字幕。

要独立修改辅助层，必须有不含这些辅助效果的干净源录屏，并把区域框、暗场和点击光圈单独制作。已有录屏含鼠标时不叠加第二个；已有框和指针已经烘焙时，不能假装它们可独立移动，应保留原效果或从干净源素材重做。确有真实输入事件记录且录屏没有指针时，可以按记录呈现唯一指针，不凭旁白编造点击。

完成后按最终编码视频核对每个方位词的发声帧、点击帧、页面就绪帧、滚动停稳帧和焦点退出帧；事件日志只能辅助，不能代替画面检查。检查 100% 尺度的文字清晰度、唯一指针、焦点区域与旁白一致、接缝无旧框和黑帧，交付同步表与实际导出预览。新界面须重新测量区域和时间，不复用旧页面坐标。
```

## 输入与替换范围

| 输入 | 用途 | 缺失时 |
| --- | --- | --- |
| 目标时间段、真实录屏 | 建立操作来源与画面范围 | 请求真实素材，不生成假界面 |
| 已批准配音 | 提取真实发声时间窗 | 可先规划流程，但不宣称已经声画同步 |
| 操作目标和顺序 | 确定哪些对象值得指向 | 从当前讲解及真实页面核对，不补不存在的功能 |
| 干净源录屏或可补录环境 | 支持独立辅助层与错位修正 | 保留烘焙效果或请求源素材，不承诺移动已有指针 |
| 输入事件记录 | 辅助核对真实点击与到位时间 | 逐帧检查可观察动作，不能推测不存在的操作 |
| 强调色与安全区 | 控制框、暗场和点击光圈 | 继承原片视觉并避让关键文字 |

## 导演方法

### 用实际发声定位

对应表至少记录发声区间、对象、指针到位、点击、结果可见和焦点退出。方位词出现时对象应已到位，动作词应与真实动作在对应窗口内吻合。具体提前量依据实际录屏与音频校正，不给所有素材硬套同一个偏移量。

### 把滚动和阅读分开

复杂流程图可以按同一规则逐节点导览：先滚到所讲节点，停稳后框选，讲解完成再移动。跨页面先清框，不能让旧坐标在新页面圈住无关内容。无需为了“有动效”持续摇动、缩放或移动鼠标。

### 保留操作因果

修剪等待不等于更改系统事实。保留真实错误、校验提示和来源；如需使用另一次真实完成结果，应说明素材批次的关系。没有真实操作来源时，不用抽象动画冒充实操。

## 与其他 Prompt 的区别

Prompt 007 处理单个页面的输入标注与焦点锁定；本 Prompt 编排跨区域、跨页面的真实操作，并以旁白时间窗校正动作和反馈。它可以采用类似的细框视觉，但复用核心是同步方法，不是固定坐标或固定时长的焦点动画。

## 可编辑性与验证边界

- 干净源录屏加独立辅助层，才支持后续单独修改框、暗场、脉冲和时序。是否真的可编辑，应检查实际工程，不能只看导出外观。
- 已合成视频里的鼠标与辅助框可能已烘焙；该成片只能作为方法参考，不能承诺在编辑器里逐项改动。
- 原片已检查的镜头不证明新录屏已同步。换录屏、改配音、变画幅或重排页面，都必须重新核对成片帧。
- 原案卷录屏、逐词私有素材、内部标识与下载地址均不随本页公开；本条目前没有公开视频或换料后代表渲染。

## 换料后的验收

- 开场方位词与指针、区域框一致；每个页面只存在一个有效指针。
- 真正点击时才有脉冲，反馈和结果只在页面实际出现后讲解。
- 滚动停稳后焦点准确，不遮字、不提前滚走、不把旧框留在新页。
- 检查源片到成片映射，未篡改结果，批次关系与等待修剪清楚。
- 最终导出中的中文清晰、音频未截断、前后接缝干净；交付逐项同步表和可编辑性说明。
