# CutDirector 使用指南

[← 返回首页](../README.md)

## 安装

CutDirector 是一套给智能体使用的剪辑规则，不是独立视频编辑器。实际处理使用当前环境已有的媒体处理、语音识别能力。

### Codex

在 Codex 对话中发送：

```text
$skill-installer install https://github.com/Fangx-AI/cut-director
```

安装后重启 Codex。

### Claude Code 或手动安装

下载完整仓库，把整个目录放到对应位置，再重启智能体：

| 智能体 | 安装目录 |
| :--- | :--- |
| Codex | `~/.codex/skills/cut-director` |
| Claude Code | `~/.claude/skills/cut-director` |

`~` 是用户主目录。`SKILL.md` 应直接位于 `cut-director` 下，`references/`、`scripts/` 等目录一同保留，不要只复制一个文件。

## 第一次剪辑

把视频放在智能体可以读取的位置。

**Codex：**

```text
使用 $cut-director 剪干净这条口播并配字幕：<视频路径>
```

**Claude Code：**

```text
/cut-director 剪干净这条口播并配字幕：<视频路径>
```

完整语义剪辑和字幕依赖逐字时间的转写。拿不到时，按 Skill 规则只处理停顿，不制作字幕，并说明语气词、口误和重录尚未处理。

## 剪完拿到什么

- **新的视频文件**：完成粗剪，字幕烧进画面，原片不覆盖。
- **SRT 字幕**：可继续校对或导入其他编辑器。
- **剪辑与字幕改动记录**：和成片保存在一起，记录删除原因，以及原片和成片的时间对应。

交付时会说明剪前、剪后时长，并最多指出三处值得复听的位置。自检说明应区分文件检查与实际看过、听过的部分。

## 调整某一处

用**成片里的时间**描述问题：

```text
成片 1:05 那句话换成前一遍，其他地方保持不变。
```

保留原片、转写和剪辑记录，方便重剪及同步更新字幕。

## 按你的习惯剪

| 你想要 | 在指令中加一句 |
| :--- | :--- |
| 默认自然节奏 | 不需要额外指定 |
| 节奏更快 / 更慢 | “节奏紧凑一点” / “节奏舒缓一点” |
| 只做粗剪 | “不要字幕” |
| 字幕另行导入编辑器 | “只给 SRT，不烧进画面” |
| 先审阅再出片 | “先给我看删除清单，确认后再剪” |
| 换字幕样式 | “字幕用 highlight 样式，突出关键词” |

[查看六种字幕样式](subtitle-gallery.md)。需要逐字变色时，必须有真实逐字时间。

## 范围与规则

当前范围是口播粗剪和字幕，不包含配乐、B-roll、调色和额外视觉特效。拿不准的内容默认保留。

- [Skill 入口](../SKILL.md)：流程、硬规则与交付约定。
- [剪辑规则](cut.md)：删什么、留哪一遍、在哪里下刀、如何自检。
- [字幕规则](subtitles.md)：文字校对、断句、时间同步与安全位置。
- [字幕样式参数](subtitle-styles.md)：高亮词、字体、逐字时间与脚本调用。
