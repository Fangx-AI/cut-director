# Prompt 007: 高清页面输入标注与焦点锁定

这个 Prompt 用真实、高清的网站页面作为底图，再叠加可编辑的输入标注、暗场遮罩和目标焦点框。复用的是镜头结构与节奏，不是演示页面里的固定文字或产品内容。

> **类型：真实页面素材 + 可编辑 Motion Graphic 标注层。** 页面必须来自用户提供、项目中已验证的截图或录屏；标注层必须明确属于后期讲解，不得伪装成网站原生界面。

[观看已验证演示视频](../assets/verified-prompts/prompt-007-hd-page-focus-lock.mp4)

## 用户直接使用的通用 Prompt

```text
在 [目标时间段] 制作一段“高清页面输入标注与焦点锁定”镜头。独立演示默认使用 1920×1080、30fps、2.5 秒。底层只使用用户提供或当前项目中来源可验证的真实网站截图/录屏：[真实页面素材]；素材应至少达到目标输出分辨率，按 1:1 或等比 contain 放置，禁止放大低清截图、AI 重绘、虚构产品 UI、拉伸或无意义裁切。

在真实页面上方添加透明 Motion Graphic 讲解层，以下内容与样式都要独立可编辑：[编辑标注]、[字段标签]、[输入文字]、[焦点标签]、强调色、文字色、面板色、遮罩色与遮罩强度；焦点框的 X、Y、宽、高和圆角，以及标注面板的 X、Y、宽度也要暴露为可编辑属性。未填写的可选标签直接隐藏并自动回流，不留下空框、骨架线或占位词。所有新增标签必须被识别为“后期讲解标注”，不得冒充网站原生按钮、搜索框或系统反馈。

时间轴固定为：标注面板第 0–14 帧克制入场；第 8–34 帧逐字输入 [输入文字]；第 14–30 帧让页面非重点区域逐渐压暗；第 20–38 帧绘制并锁定目标焦点框；第 28–42 帧显示 [焦点标签]；第 42 帧后只做轻微呼吸强调并保持到第 74 帧。焦点框必须准确贴合 [目标区域]，不得遮挡目标正文，也不要用大幅推拉或过度模糊制造“聚焦”。

先检查原始页面在 100% 尺度下是否清晰，再展示首帧、输入中段、遮罩建立、焦点框落位和最终保持帧；确认页面文字未变糊、标注与原生 UI 边界明确、焦点坐标准确后再导出。
```

## 用户需要替换什么

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 真实页面素材 | 是 | 用户提供或项目中已验证，分辨率不低于目标输出 |
| 输入文字 | 是 | 保留为可编辑文字，不烘焙到截图 |
| 目标区域 | 是 | 用焦点框坐标准确贴合真实页面目标 |
| 编辑标注 / 字段标签 / 焦点标签 | 否 | 留空时隐藏并回流 |
| 颜色、遮罩强度、圆角 | 否 | 服务于原页面，不覆盖可读内容 |

## 固定的动画骨架

- 画布：1920×1080，30fps，75 帧。
- 页面层：真实素材满画布等比显示，不放大低清图。
- 标注层：透明 Motion Graphic，文字、颜色、位置均可编辑。
- 输入：第 8–34 帧逐字出现。
- 聚焦：第 14–42 帧完成暗场、焦点框与焦点标签。
- 收尾：第 42–74 帧稳定保持，不闪黑、不突然缩放。

## 真实素材边界

Prompt 007 不负责“画一个像真的网站”。没有清晰、可验证的页面素材时应请求原图或录屏，不能用骨架屏、灰线、生成图或重新绘制的界面冒充真实产品。后期标注应在视觉和语义上保持编辑层身份。

## 验证清单

- 页面在 100% 尺度下清晰，没有二次放大造成的糊边。
- 输入文字、四类标签、颜色、遮罩与焦点坐标均可独立修改。
- 焦点框贴合真实目标，不遮挡正文。
- 第 0、20、34、42、74 帧以及实时播放均无闪黑、裁切或突兀退场。
