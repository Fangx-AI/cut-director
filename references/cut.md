# 剪辑

## 删什么

| 类型 | 怎么认 | 怎么处理 |
| --- | --- | --- |
| 长停顿 | 真实静音超过节奏上限（按响度量，不按识别时间戳的间隔） | 缩短到目标长度，不删光 |
| 语气词 | 单独的"嗯、呃、额"；"啊、哦、就是、那个、然后"前后都有停顿、单独成一截时也算 | 删 |
| 口吃 | 紧接着、逐字相同地重复 5 个字以内（"我我我""除非你是除非你是"），在句中也算 | 留一次 |
| 改口 | "三月……不对，四月" | 删说错的部分和"不对" |
| 重说 | 同一句又说了一遍：开头相同，或意思相同。往后看到约 60 秒 | 留一遍（见"留哪一遍"） |
| 残句 | 话说一半停住，换了说法重说 | 删整个残句 |
| 重来口令 | "重来""等一下""这段剪掉"、拍手、长停顿后从句首重说 | 删被放弃的那一遍，连同口令和拍手声 |
| 连词叠用 | "然后但"，后一个推翻前一个 | 删前一个 |
| 场外话和杂音 | 对镜头外说话、试录、咳嗽、清嗓、碰麦 | 删 |
| 开头结尾 | 开口前、说完后的空白 | 删 |

## 不删

- 排比、强调、设问、刻意对比："要快，要准，还要稳""非常非常关键""不是 A，而是 B"。
- 笑声、反应、包袱前的停顿（可缩短到 0.4–0.6 秒）。
- 说话人的口头风格、粗口、引文。
- 开头第一句（钩子）。觉得开场弱，交付时提一句，不改。
- 识别错字：转写错了不等于说错了。
- 远距离更正（1:10 说"10 种"，3:20 说"刚才说错了，是 20 种"）：默认两处都留，交付时一定要提。

## 留哪一遍

依次比较，分出高下就停：

1. 内容完整、没说错。
2. 流畅：没卡顿、没语气词、没长停顿。
3. 语气自信，和前后句接得上。
4. 看镜头、没低头看稿：每遍取开头、中间、结尾各一帧比较。
5. 都差不多，留最后一遍。

两种特殊情况：

- **边说边改主意**：每遍意思都不同（"对社会有用"→"对大家有用"→"对用户有价值"）。留和下文接得最顺的一遍，交付时提。
- **交叉重录**：第一遍说完，冒出半句别的，又换个说法重说一遍。两遍留一遍，中间的半句一起删。

## 删到哪里

- 重说一般回到句首，从被放弃那一遍的句首删到重说开始之前，包括中间的停顿和口令。只是半句重复（"可以，可以"）时只删重复的字。
- 删完把剪后全文从头读一遍：剪辑点两侧不能有重复的词，相邻两句开头不能相同，不能留下半截口误，"它""这个"指的东西不能被删掉。
- 拖长的字（"那——个"）在转写里可能像"短字＋停顿"，整个留或整个删，不要从中间切。
- 转写里的叠字（"画的画的"）可能是识别错了。截出那几秒换一个识别再听一遍，两次一致才删。

## 节奏

| 节奏 | 停顿超过 | 缩短到 |
| --- | --- | --- |
| 紧凑 | 0.3 秒 | 0.2 秒 |
| 自然（默认） | 0.45 秒 | 0.3 秒 |
| 舒缓 | 0.7 秒 | 0.45 秒 |

缩短后的停顿四成留在下一句开口前，六成留在上一句说完后。删掉一段内容后，接缝处也按这个长度留停顿。

## 下刀

- **静音阈值**按素材定：每 10 毫秒响度取第 10 百分位作底噪，加 6 dB。人声比底噪高不到 8 dB 时响度不可信，改靠逐字时间。
- **贴靠**：剪辑点上还有声音，就把保留段往外扩到静音，最多 0.25 秒，不越过相邻的字。
- **没有静音可贴**（中文连读很常见），依次试：
  1. 换一种等价删法：重复的内容删哪一遍文字都一样时，删边界在静音里的那一遍。
  2. 多删一两个字，退到最近的停顿，意思不能变。
  3. 在 ±60 毫秒内找最安静的点下刀，交付时把这个接缝列为值得听的地方。
  4. 都不行就不删。
- **帧**：不要把剪辑点吸附到整帧，低帧率素材一帧可能 60 毫秒，会切进字里。音频按精确时间切，视频按累计时长取整到帧。
- **画质**：重新编码不低于原片，例如 H.264 CRF 18–20。
- **跳切**可以接受。剪辑点由话决定，挪不动就不挪。

## 转写

- 识别前，把视频里会出现的人名、品牌、术语作为热词交给识别：用户提到的、文件名里的、开头几句里听到的。剪辑和字幕都用这份转写，这里没给，字幕阶段只能逐个改。
- 很多识别会把"嗯、呃"过滤掉。能打开"保留语气词"就打开；不能时，找字与字之间有声音、却没有文字的片段，长于 0.2 秒才当疑似语气词。
- 有的识别会把口吃"顺"掉：说两遍只认一遍，并把旁边的字拉得很长。某个字超过 0.6 秒，那里可能藏着重复。
- 识别出的标点可能错位一个字，按 0.3 秒以上的停顿分句，不靠标点。
- 只有句级时间的 SRT 切不准字，只能当参考。
- 转写存下来，重剪和做字幕直接复用，不对全片跑第二遍。

## 自检

- **时长**：成片等于保留段之和；音轨和视频轨相差不超过 0.1 秒。
- **停顿**：用原片的静音阈值查成片，没有超过节奏上限的停顿。
- **切坏的字**：把成片重新识别一遍，和"原文减去删除项"逐句对照。接缝附近文字对不上，说明切坏了，撤回那个删除项。
- **接缝**：每个剪辑点前后看画面和波形，没有爆音、闪帧。音量明显高于静音阈值的接缝，列为值得听的地方。
- **比例**：流畅口播通常删 5%–30%，重录多的可到 40%–70%。删超过六成，或保留片段中位长度不到 0.7 秒，回头查是不是删多了、剪碎了。
- 有问题就改，最多三轮。

## 剪辑记录

和成片放在一起：每个删除项的类型、原片时间、原话、理由，以及每个保留段在原片和成片里的时间对应。改某一处、做字幕都靠它。
