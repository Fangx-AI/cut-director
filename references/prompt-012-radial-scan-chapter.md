# Prompt 012 · 环形扫描章节转场

**状态：experimental · 从成片提炼，待通用换料验证。**

把一段独立的章节切换做成短促的全屏视觉停顿：扫描环聚拢，标题落稳，下一章节的真实画面接上。适合科技产品、技术讲解和软件演示的章节边界。

## 通用 Prompt

```text
在 [章节边界] 制作约 [时长，默认 2 秒] 的全屏环形扫描章节转场，中央准确显示「[章节名]」。沿用原片画幅、帧率、字体与 [背景色/强调色]，不要把横屏示例的尺寸强加到其他画幅。

用前后错开的同心扫描环、短弧和细刻度建立向中心聚拢的运动，形成空间纵深。标题随聚拢动作清晰落位；字面保持明亮、完整、正向可读，装饰避开标题，辉光只作边缘点缀。默认只有一行短标题，不自动添加序号、英文、伪代码或额外口号。

将标题保留为独立可编辑文字层，背景环、扫描光和字层分开。使用能正确显示目标语言的字体，逐字核对章节名；不能让视频生成模型直接生成需要准确识读的文字。标题、字体、色彩、环的速度、辉光强度和时长作为复用时需要开放的属性，完成后检查实际可编辑性，不能把一个成片 MP4 当作已具备这些属性的模板。

先让扫描环与标题入场，再稳定展示标题，最后衔接下一章节的真实首帧。2 秒示例可按约 0.4 秒入场、1.2 秒清晰保持、0.4 秒出场分配；这只是换料起点，长标题应增加保持时间或调整排版，不能读不完就离场。背景可以继续缓慢运动，标题落稳后不持续抖动或反复闪白。

如使用短掠过音效，对齐视觉收束点，并避让上一句旁白的收尾。原片配音保留完整；需要增加时间时延后后续镜头并保持声画对应，不截断旁白强行塞入转场。导出前检查前镜末帧、入场、标题稳定帧、出场和下一镜首帧，确认无错误中文、无残留上一镜、无黑帧或遗漏的下一镜内容。
```

## 可替换内容

| 输入 | 用法 |
| --- | --- |
| 章节边界 | 已确认的插入点，以及前后镜头的实际首尾 |
| 章节名 | 用户提供的准确短标题；示例四字，不强制所有语言为四字 |
| 时长 | 默认 2 秒；根据阅读时间与前后旁白调整 |
| 背景与强调色 | 继承原片；示例为深蓝背景、青色扫描环、亮色标题 |
| 字体、画幅、帧率 | 按目标项目适配，先检查字形与标题安全区 |
| 音效 | 可选；使用来源明确的音效，并保护旁白尾音 |

## 与已有 Prompt 的区别

[Prompt 004](prompt-004-top-chapter-progress-rail.md) 是贯穿视频的章节导航与进度条；本条是占用独立时长的全屏章节切换。不要为了使用本条，把每个普通剪辑点都做成章节。

## 复用时的检查

- 开始：确认真实章节边界、原片画幅和旁白尾音；新增时间有明确去向。
- 中段：按原比例检查中文、字形、对比度与稳定阅读时间；装饰不能穿过字面。
- 结束：检查上一镜、转场和下一镜的连续帧，并回听接缝；没有音轨的公开样片不能替代这一步。
- 编辑性：在新工程中实际修改一次标题与强调色，再检查属性是否生效；原节选 MP4 的字与环已合成，无法单独修改。
