# 从口播原片到可交付剪辑

用户给视频并描述想要的结果即可。先复用已知素材、风格、画幅和授权，缺少真正必要的来源时才补问。一次只做字幕或一个 Logo 时，直接进入对应环节。

## 1. 看素材，明确剪辑范围

- 区分毛片、已接受粗剪和已完成成片。动画请求默认保留原声剪辑；“把这条口播剪好”包含语音清理和节奏整理。
- 读取素材时长、音视频、实际转写、已有时间线和风格。多段素材保留用户给定顺序，按来源身份去重；不要把两次相似录制当成同一个文件。
- 默认保持原画幅和自然节奏。沿用用户给出的平台、目标时长、保留句与禁删段。
- 没有可读音频时，只能提出剪辑建议。没有词点时，不靠一句 ASR 段落的起止时间精剪单个字。

## 2. 剪语音，先交付能听的版本

读 [语音剪辑规则](speech-editing.md)。区分无意义口癖、失败重录、重复内容、制作闲聊和有表达作用的重复。选择完整说法，压缩空等，修复接缝。

用户已要求清理时，直接执行范围内可恢复的剪辑。用户要求“先看方案”或“只预览”时先展示建议，不应用。对不确定且会删除独有信息的段落，保留并提出一个具体选择。

回读当前 Script，试听修改接缝、完整语义和段落衔接。展示粗剪链接或可播放预览、前后时长和最重要的改动。反馈“太快”“这句留着”时只调整相关段落，复用其余已接受决定。

## 3. 固定当前时间，再做字幕与画面

所有字幕、手势、动画和音效以当前粗剪为时间依据。原片与剪后片必须区分。

- 当前宿主可直接返回剪后 Script / transcript 时，优先使用它。
- 已有源词点与线性 1x 保留区间时，可用 [剪后时间映射](speech-edit-plan.md) 算出当前时间。
- 原片中已经被删除的词或手势，不应继续触发效果。被切成两段的锚点需要重新设计。
- 变速、转场重叠、多机位或音频另行剪辑时，回读实际宿主映射；本地线性工具不适用。

## 4. 字幕服务可读性

使用剪后真实原声生成字幕；修正 ASR 错字，保留否定、数字、单位、专名和说话者。参考稿帮助校对，但不能把没说过的句子写成已说过。

按语义和阅读长度断句，避免把限定词或金额单位拆开；换行是排版操作，不是修改音频。重点文字与常规字幕只保留一个主焦点。检查横竖屏、底部界面避让、实际字体、长句和动画占位。

## 5. 动画、特效与补画面

沿用现有 [Prompt 库](../PROMPT-LIBRARY.md) 与视觉导演规则。根据观看任务选择关键词、Logo、步骤、图表、页面标注、B-roll 或生成画面；入场跟随当前原声或手势，整条片统一字体、色板和运动方式。

先验证代表性效果再在已授权范围扩展。已有接受风格的局部调整不用重新走全片创意流程。跳切覆盖优先使用有信息价值的真实录屏、辅助画面或合理构图，不为遮切口插入无关素材。

## 6. 声音与节奏

先保证人声清楚、无接缝爆音和意外静音。降噪、人声隔离和响度处理按实际问题选择；效果过强导致机械音或吞字时降低强度。

用户要求背景音乐、音效或完整声音处理时再安排；完整剪辑可以推荐，生成费用仍遵循宿主授权。音效对准当前信息落点，音乐在说话时避让。不得靠字幕读起来顺就声称音频已经自然。

## 7. 验证与交付

| 环节 | 必须观察的结果 |
| --- | --- |
| 语音 | 无失败重录、断词、遗失上下文或误删限定；重要接缝已试听 |
| 时间线 | 原声与人物同步，主画面无意外黑帧，剪后时长和顺序正确 |
| 字幕 | 与剪后语音一致，无旧词残留、旧时间偏移或遮挡 |
| 动画 | 起止、可读保持、人物和字幕避让、退出后恢复正常 |
| 声音 | 人声可懂，音效不过响，音乐不盖住讲解，无爆音或意外静音 |
| 导出 | 文件可解码、有音视频、实际分辨率符合请求、首尾正确 |

根据任务展示可编辑项目、预览和用户要求的导出。分辨率以实际文件为证据；把 1080p 放大到 4K 不等于 4K 素材质量。记录未完成的具体检查，保留原片和可恢复的粗剪版本。

本流程新增了语音剪辑指导。现有 ChatCut 已验证标签只证明对应动画在原验证范围内完成过，不能代替新语音清理的真实试听验证。
