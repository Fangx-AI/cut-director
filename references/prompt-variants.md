# 旧素材的画幅与焦点变体

[返回素材索引](../PROMPT-LIBRARY.md)

以下是可复制的适配指令，尚未通过 ChatCut 变体验证。它们保留旧素材的任务，不增加重复编号。原版演示的验证状态不覆盖这些变体。

## 007 · 同一页面内跟随重点

```text
在 Prompt 007 的真实页面焦点锁定基础上，依照 [关键词 A] 和 [关键词 B] 的真实词点，把高亮区域从 [区域 A] 移向 [区域 B]。
全程使用同一份真实素材和固定视窗。必要时在视窗内平移、放大原图，让标题与相关数值一起可见；不另造一张放大卡片，不重绘 UI。
只在素材分辨率足够时放大。检查两个落稳帧、运动中点和退出后一帧，字幕与人物保护区继续有效。
```

## 006 · 三卡适配 3:4 / 4:3

```text
把 Prompt 006 的三张正反面卡片适配到 [3:4 / 4:3]。这是适配版，不要求复制横版的像素尺寸。
3:4 优先纵向三卡，4:3 根据最长文案选择横排或纵排；保持三张卡的身份、信息层级及依次翻面的关系。只在侧边时切换正反面。
不要把完整横版缩成竖版中间的小窗。先展示最长正面与背面的落稳构图，再检查完整翻面。无法读清时缩短可选说明，不默默把所有字缩小。
```

## 008 · 竖版图片卡组

```text
把 Prompt 008 适配为 [3:4 / 4:3]。使用原有真实图片，不重复图片凑数。
竖版把卡组的展开方向更多分配到纵向，主卡保留图片关键区域与标签；4:3 根据图片比例调整扇面，避免卡片之间挡住必要信息。
入场后直接建立卡组关系，不额外洗牌。主卡抬升只发生一次。检查最长标签、最窄图片、主卡落位和退出帧。
```

## 004 · 不同片型的密度

短案例合集可只显示当前编号与进度；长教程适合章节导航；已经有清楚章节设计时可以不加。进度仍按真实时长连续推进，不能每个案例重新归零。

## 共同验收

实际检查目标画幅中的阅读尺寸、字幕与人物、真实素材裁切、入出场边界。没有执行过的比例标注“待验证”，不要用容器等比缩放证明自动适配完成。
