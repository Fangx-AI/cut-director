# Prompt 013: 原页拆层与出处锚定

把一份真实资料拆成“整页上下文、关键片段、出处位置”三层，让观众看清重点，同时知道它来自哪里。适合报告、论文、合同、账表和资料核对；行业、标题和重点内容均由本次素材决定。

> **状态：experimental。** 原片中的实际拆层镜头已检查，通用 Prompt 换料后的代表镜头尚未重新渲染验证。原案卷素材不公开，本页不提供或虚构公开视频。它是从成片提炼的制作方法，不是已经交付的参数化模板。

## 用户直接使用的通用 Prompt

```text
在 [目标时间段] 把 [真实文档原页] 做成“原页—关键片段—出处”的三层溯源镜头。使用同一份资料中可核对的 [关键表格/段落/图表区域]、[需要强调的原句或关键值] 和 [页码/文件标题/引用位置区域]，画幅与帧率继承目标视频。

先稳定展示原页的整体上下文；随后让关键片段从它在原页中的真实位置平滑抬升到前景，原页略微缩小、后退并轻微压暗，仍然可辨认。再把原页中真实存在的出处区域抽出为第三层，保持“完整资料—局部证据—来源位置”的对应关系。用 [强调色] 细框或短扫描光突出目标原句或关键值，保留必要的表头、单位和上下文。前景落稳后留出阅读时间，结尾保持三层关系或平滑回收。

三个图像层必须来自同一可靠原页，允许从同一源文档重新取得更高清的相同区域；不得拼接其他页面的数值或出处，不得生成、重绘、改写原文。若局部放大后不清晰，重新获取高分辨率原页；无法取得时缩小放大幅度或保持整页，不把低清插值称为高清。原页没有可核对的出处区域时，不编造页码或引用条，先使用清晰的整页与关键片段两层。

将源图、裁切区域、层间距、运动方向、强调框和可选 [说明标题] 分别组织。图像内部的文字、数字和表格仍是引用图像，不能宣称可作为文字属性编辑；可选说明标题使用独立可编辑文字层，留空时隐藏。新增说明不冒充原文，标题避开文件标题，出处层避开关键内容；本镜头不自动增加逐句字幕，也不改变原旁白。

先检查整页建立、片段离开原位、出处落位和最终阅读状态，再核对实际导出中的原文一致性、局部清晰度、图层遮挡、前后接缝与可编辑性边界。换用新资料后重新验证，不沿用其他素材的裁切坐标或验证结论。
```

## 输入与替换范围

| 输入 | 用途 | 缺失时 |
| --- | --- | --- |
| 目标时间段、画幅、帧率 | 决定阅读时间和画面容纳范围 | 先检查目标视频并沿用已确认范围 |
| 真实文档原页 | 三层共用的事实来源 | 请求源资料，不生成替代文书 |
| 关键区域及原句或关键值 | 决定裁切与强调位置 | 从已有讲解明确目标，不随意抽取数值 |
| 出处区域 | 指明本页在资料中的位置 | 没有真实出处区域时降为两层，不补假页码 |
| 说明标题、强调色、移动方向 | 控制后期讲解层 | 标题可省略，样式继承目标视频 |

## 动作与安全区

1. **建立整页**：先让观众辨认资料，不能直接丢出一个失去上下文的数字。
2. **从原位抽出**：关键片段沿一条清楚路径移至前景；原页退后形成层次。保留表头、单位与解释条件，避免断章取义。
3. **出处落位**：出处层从同页的真实位置进入，给正文留出阅读空间；没有这一层的事实依据就省略。
4. **稳定阅读**：装饰运动减弱，关键文字保持正向、清楚。保持完整关系或回收到原页，不用突然黑帧结束。

这不是多张图片卡片陈列，也不是在原页上锁定单个焦点；三层应始终能追溯到同一源页。原页、片段、出处的尺度要逐项检查，不能只因为输入整图达到输出分辨率就假定局部放大也清晰。

## 可编辑性边界

- 新制作时可以独立组织图片层、裁切、位置、时序和强调框；具体属性是否可在编辑器中修改，以实际交付项目的属性检查为准。
- 原图中的文字与数字不是可编辑文字层。更换资料需要重新核对来源、裁切和时长。
- 只有一个已合成的视频文件时，拆层动作和原文已经烘焙，不能承诺直接逐层修改；需要源图片与工程重建。
- 本次提炼没有发布原案卷、截图、私有素材标识或下载地址，也没有公开代表渲染。原片验证不等于通用换料模板验证。

## 换料后的验收

- 三层的原文、表头、数值、单位和出处与同一真实源页一致。
- 在最终输出尺寸检查关键区域；放大后的文字不模糊、不被扫描光遮住。
- 抽出过程从正确位置开始，不出现其他页内容，也不把后期标注伪装为原文。
- 说明标题与出处层不压住阅读区，最终状态有足够阅读时间。
- 检查实际图层与属性，准确说明哪些可改、哪些已烘焙；再检查导出首尾和实时播放。
