- 两支 MP4 通过完整解码检查，已移除自动生成的静音音轨。
- 010 检查了消息、准确数量、收益句三个阶段与最终保持；第 0 帧为文字入场前的背景状态，没有上一镜素材。
- 011 检查了初始卡片、中列停留、部分完成和全部完成；卡片保持原有名称，移动时不覆盖列名。
- GIF 为同一 MP4 的 640 像素宽、12fps 预览。以 MP4 为完整帧率演示。
- TypeScript `tsc --noEmit` 通过；仓库校验仍为 9 条 recipe；现有 20 项 unittest 通过。
- 文案和配色的替换入口已在源文件中提供。未声称对所有长度、颜色、画幅或任务数量组合完成测试，范围限制见各 Prompt 说明。
