# 新增口播剪辑的验证范围

语义判断场景见 [S12–S20](scenarios.md)，评分见 [口播量表](rubric.md)。这些场景不是已经通过的真实视频案例。

工程、安装与实际项目页检查见 [2026-10-04 检查记录](quality-review-2026-10-04.md)。历史视觉前向评分不代表当前语音分支已经通过回归。

`test_speech_edit_plan.py` 使用 [合成剪辑计划](fixtures/speech/natural-cleanup.json) 验证：

- 保留区间连续组装、剪后时长与偏移计算。
- 已删除或拆分锚点不能直接沿用。
- 可信词点不被剪开，区间越界与重叠被拒绝。
- 多素材顺序、显式重排、版本更新和不适用的变速/转场字段。
- Windows CLI 的 UTF-8 JSON、异常输入和输入文件保护。

合成样本预先选择了正确数字、完整引入、有作用的“然后”、词内“额”和强调句。测试只证明代码正确处理这些已选区间，不证明模型能在所有素材上自行选对。

真实 ChatCut 回归仍需有权使用的中文毛片。按[一条素材完整验收方案](speech-acceptance.md)检查预览不越权、自然粗剪、原声局部恢复、剪后字幕/动画与实际导出。完成后记录宿主、源范围、关键接缝、误删与漏删、回退修改和可播放结果，再将该范围标为已验证。
